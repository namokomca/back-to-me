# 다시, 내 자리

육아휴직을 마치고 돌아오는 부모와 배우자가 복직 준비, 등하원 분담, 직무 AI 연습을 함께 기록하는 모바일 웹앱입니다.

## 구현한 기능

- 복직일과 아이 정보를 기록하고 남은 날짜를 확인합니다.
- 회사 연결, 아이 돌봄, 일 감각, 자기 돌봄 준비를 작은 할 일로 나눕니다.
- 두 사람의 근무시간과 직접 입력한 이동시간으로 평일 등하원 담당과 돌봄 공백을 계산합니다.
- 집, 기관, 직장 주소와 교통수단을 기록합니다. 지도 검색과 실제 경로 API는 아직 연결하지 않았습니다.
- 체온계와 여벌옷 위치, 배우자에게 남길 말을 기록합니다.
- 가상의 직무 과제로 AI 요청 문장을 연습하고 OpenAI Responses API로 피드백을 받습니다.

## 현재 범위

기본 기록은 브라우저 localStorage에 저장합니다. Sites 배포본은 Cloudflare D1과 로그인 계정 ID를 이용해 같은 계정의 여러 기기에서 명시적으로 저장하고 불러오기를 지원합니다. 동시 수정 충돌은 덮어쓰지 않고 안내합니다. 배우자 별도 계정 초대, 실시간 자동 동기화, 푸시 알림, 지도 기반 이동시간은 아직 지원하지 않습니다. 로컬 서버에는 Sites 인증과 D1이 없으므로 온라인 저장은 배포본에서만 사용할 수 있습니다. 화면의 부모 이야기와 가족 정보는 설명을 위한 가상 예시입니다. AI는 서버에 유효한 키가 설정되어 있을 때 동작하며, 키가 없으면 기본 기능만 사용할 수 있습니다.

가족 이름, 생일, 주소를 AI 요청에 자동으로 포함하지 않습니다. 사용자가 직접 작성한 질문과 직무, 복직일, 돌봄 공백만 전송합니다. 질문 안에 개인정보나 회사 기밀을 적지 마세요.

## 실행

Node.js 22.12 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
```

브라우저에서 http://127.0.0.1:4174 를 엽니다. 프런트엔드와 API 서버가 함께 실행됩니다.

AI를 사용하려면 `.env.example`을 `.env.local`로 복사하고 본인의 `OPENAI_API_KEY`를 설정합니다. 이 파일은 Git에 올리지 않습니다. 기본 모델은 `gpt-6-luna`이며 계정에서 이용 가능한 모델로 `OPENAI_MODEL`을 바꿀 수 있습니다.

```sh
pnpm test
pnpm build
pnpm start
```

빌드 결과는 http://127.0.0.1:4173 에서 확인합니다. 현재 서버는 로컬 사용을 위한 구현입니다. 외부 배포 시 호스팅 인증, 요청 한도와 서버 비밀키 설정이 필요합니다.

React, Vite, Tailwind CSS, Node.js, OpenAI Responses API. 외부 UI 컴포넌트 라이브러리는 사용하지 않습니다.
